## 🎮 Featured game: Echoes of Kharon — Definite Space Saga

> A 2.5D shooter that turns into a mech platformer mid-run.

<!-- Replace with a real GIF: 10–15 s, under ~5 MB, showing the ship-to-mech transformation -->
<p align="center"><img src="https://raw.githubusercontent.com/nikolaskorakidis/mecha-techa-soldier/main/docs/media/gameplay.gif" width="720" alt="Gameplay: ship transforms into a mech"/></p>

You fly a rescue craft into a shattered orbital foundry. Decode enemy attack patterns, steal them as weapons, then transform from starfighter to bipedal mech when the station falls toward the planet.

- **Echo Shift** — Burst, Arc and Guard modules decoded from enemies, carried across the transformation
- **Two genres, one machine** — horizontal shooter (Orbital Riptide) → action platformer (Foundry Run)
- **Two bosses** — the Choir Engine and the Forge Regent
- **Built with** Godot 4 + typed GDScript, component-based architecture, data-driven tuning via Resources, headless test suite

**Status:** vertical slice in active development · Windows first, macOS dev
➡️ [View the repo](https://github.com/nikolaskorakidis/mecha-techa-soldier)
